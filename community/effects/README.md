# community/effects

One contributed effect per file, `<slug>.json`, nothing else. No images, no
folders, no assets.

Read `CONTRIBUTING.md` at the repository root before you add anything - it is
written for the agent doing the work and lists every rule the check enforces.

The short version:

```bash
python -m aetherfx.community check community/effects/<slug>.json --previews out/previews
```

must exit `0`. That means, in one sentence each:

* **Procedural only.** Every texture and mesh is built by the engine. No
  `source: file`, no `path`, no URL, no image or video file named anywhere.
  Reference art never enters this repository.
* **MIT.** `metadata.license` is `"MIT"`, so anyone can ship your effect in a
  game.
* **Credit.** `metadata.author = {"github": "<your username>"}`. That is the
  whole account model: no sign-up, no e-mail. `name` is optional.
* **Deterministic.** The same document simulates to the same frames every time.
* **Inside budget.** At most 6000 live sprites, 300 live mesh particles, 160
  nodes, 12 s, 96 MiB of baked texture, 6 s of texture baking.
* **Tuneable.** At least three named style controls.
* **House style.** No crosses or four-armed stars, no constant-width tube
  beams, no hard-edged ribbons, and a projectile always ends in an impact.

`../index.json` is generated by `tools/build_community_index.py`; do not edit it
by hand. Previews are rendered by CI and published outside the default branch -
never commit a PNG, GIF or MP4.
