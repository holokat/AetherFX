## Optional external tools and services (never bundled, never required)

- **ffmpeg**: invoked as a separate program for video export when it is on the PATH. Its own license
  (LGPL or GPL depending on the build) applies to that program only; AetherFX does not link or ship it.
- **A Chromium-based browser**: used by the developer capture tool `tools/gl_capture.py`.
- **Model providers**: the studio's Generate box can use an Anthropic API key or a local Claude Code
  login, and any MCP-capable agent can drive the engine. These are optional services chosen and paid
  for by the user; the engine, the tools and the library work without them.
- **Unreal Engine**: `engines/unreal/` is an MIT-licensed plugin written for this project. Building or
  running it requires Unreal Engine, which is proprietary software under Epic Games' licence and is not
  included. The plugin contains no Epic source code; the `.uasset` materials were generated by this
  project's own script (`engines/unreal/scripts/generate_materials.py`).
